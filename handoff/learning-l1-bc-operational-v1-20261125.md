# L1 B/C 初回集計の実行仕様 v1（結果閲覧前）
初期970半荘のみ。入口カードの支持ゲートを維持。集計は半荘別の分子・分母・異なる局数を保存し、2000回クラスタbootstrap。対立直は受理済他家立直ちょうど1人、打牌者の巡目帯1–6/7–12/13+。牌分類は対象の自己河にある同種を現物、字牌を別、数牌は両端候補の±3が自己河にある本数から筋（全て）・片筋（一部）・無筋（なし）に分類。筋は危険度カテゴリであり安全保証なし。19/28/37/456は別軸。立直後通過牌分類と書籍定義同一性は後続、現物分類は自己河のみ。実ロン率は対象立直者が実際にロンした打牌数/実打牌数。合法ロン機会率は直前の合法打牌候補を赤別物理種で重複除去し、各候補について固定された対象手・フリテン状態・ピン留めルールコアによるロン可否。第三者の優先応答は不明。三家和は実ロン精算なし。実打牌と候補機会の分母は別。
