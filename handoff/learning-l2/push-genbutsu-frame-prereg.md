# L2 対単独立直：非現物維持打牌 vs 現物手崩しの一手介入（探索母集団事前固定）
目的: 一向聴・聴牌からの押し引きの型別効果を調べる入口。完全ベタオリとの比較ではない。先制立直/ダマの実験とは異なる研究カード。
対象: 初期970開発半荘の焦点席の記録済公開turn判断。門前・自家非立直、他家受理済立直ちょうど1人、pendingReach=false、正規自摸後14枚（暗槓含め副露0に限定）、通常打牌。元のS42具体打牌が非現物（対象立直者の河の既出牌の34種集合にない）、元打牌後の構造向聴が0または1。対象立直者の河の既出牌（鳴かれた牌を含む、赤は5に統合）のみを現物とする。他家立直後の通過牌は今回は追加しない。候補は記録された合法通常打牌の具体payload（赤、手出し/ツモ切り区別）。現物候補が存在し、その中で向聴最小の打牌後向聴が元打牌より大きいこと。代替はその向聴最小の現物候補、同値は具体牌文字列のASCII昇順。手牌・自摸・合法行動から固定コアで構造向聴を再計算し、候補の合法性と物理枚数を確認。和了可能、九種九牌、槓、立直などが選択可能な局面は除外（通常打牌以外の合法行動が1つでもある場合）。Q値、実決着、隠し手牌、山、未来イベントは選定に使用しない。元行動の記録payloadのみ参照し、Qを入力しない。
層: 元打牌後向聴0/1 × 巡目1–6/7–12/13+。親子、点況、現物代替後向聴差、対象立直者親子を記述するがまだ全交差しない。決定単位/半荘単位の数を集計。元S42が非現物維持を選んだ条件付き母集団、全押し引き局面の代表ではない。現物は当該立直者への放銃回避のみ、他家への安全性を保証しない。非現物は危険度の高低や実放銃と同義でない。半荘代表選定と介入ペアのsource commitmentは母集団集計後・結果閲覧前に別固定。元打牌vs現物手崩しを一度だけ強制、その後両枝同一S42（現物枝が再度押す可能性あり）。完全ベタオリは別介入として将来設計。
一次: 当該局の局収支差。二次: 放銃/和了/被ツモ・半荘最終点/ラス/段位pt差。元全牌譜・壁・公開prefix・事前state・合法行動照合、共通壁・完走・fallback0・点数保存、秘密情報隔離。探索選定と実験結果は区別。母集団数の集計だけ着手、分岐本数は未決定・未起動。既存120先制比較と10k生成は変更なし。
