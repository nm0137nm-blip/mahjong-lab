# L1 v4 立直時点の参考打点（探索、集計前）
初期970半荘を使用。L1 v3の受理済7711件・待ち分類を維持。立直宣言打牌直後、宣言時点までに開示された表ドラのみ、通常立直1翻（ダブル立直・一発・裏・海底・嶺上等は除く）、本場/供託0、仮のロンを構造待ちごとに計算。自手/自暗槓の物理枚数から可能な通常/赤5の別を列挙。他家の隠し手や真の山、以後のドラ、実和了打点を層の定義に使わない。公知残り/フリテンによるロン可能性を問わない参考値で、全待ちで実際にロン可能という意味ではない。最低/最高の子相当ロン素点を、実際の場風/自風の役・符は変えず基本点×4から100点切上げで計算。実親子は別軸。最低値を低(2900以下)/中(2901–5200)/高(5201以上)に分類。最大値も参考に残し、帯を跨ぐ場合を別計数。各形の役符は固定エンジンに依存、独立算術で素点と支払を検算、標準符翻アンカー確認。役符そのものの独立採点なしなら仮認定に留める。パオのあるケースは別除外・報告（門前立直では想定なし）。旧件数/集計再現が必要。
主指標: 和了/放銃/被ツモ率、局収支は参考。先制/追いかけ×打点帯、親子・巡目・待ちの一軸追加（全交差は支持不足を避け後回し）。半荘クラスタ2000回bootstrap、既存支持基準100半荘/200局/陽陰各10/CI幅10pp以下。初期970は開発のみ、独立確認なし。打点帯は期待値でなく定義した参考最低ロン値、S42卓記述統計。対局中に表示する場合は自分の手の公開視点のみで同じ定義を再計算、支持不足の指標は数値非表示。実力測定モードは対局中非表示。未検証の人間確率・最適行動・因果推奨は返さない。
