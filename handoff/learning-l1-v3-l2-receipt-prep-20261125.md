# L1 v3 待ち分類・L2 分岐検証の開発記録（2026-11-25）
## L1 v3 次の集計カード（新集計前・探索）
対象は初期970半荘の受理済立直のみ。先制・追いかけを分け、親子と打牌者巡目1–6/7–12/13+を維持する。分母は対象立直者×局、同一半荘クラスタで既存2000回bootstrapと支持基準を維持する。元のv1/v2集計・外部照合未確定の結論を変更しない。
- 立直受理時の打牌後13枚相当から34種の構造待ちと一般形の全完成分解を列挙。赤は形の上では5に統合。自手・自副露で4枚消費済の牌は除外。役・フリテン・他家手牌・実山はこの分類には使わない。自手の固定面子は別途合法性確認が必要。
- 各待ち牌について両面・嵌張・辺張・双碰・単騎・七対子・国士の可能な型をすべて保持。両面のみ／両面と他の型が共存／両面なしを排他的主分類とする（両面のみは全待ち牌が両面分解のみ）。両面分解が存在するかも別変数として保持。公知牌残り上限は別指標。構造上の両面と実戦の良形を同一視しない。
- 主指標は局和了率・局放銃率・被ツモ率・局収支。副指標は和了者の実際の素点（和了時のみ、和了率と混同しない）。打点期待値の分類は立直時に見えるドラと仮定のロン/ツモ符翻、裏なし等の定義を独立採点で固定後に実施。実和了打点・将来のドラで立直前の層を作らない。
- 既存B2合計6147先制・1564追いかけと分類の合計が一致しない場合は除外を黙認せず停止し理由報告。自然牌姿の待ち集合と独立ルールコアを照合、全分類不一致0を計算ゲートとする。待ち分解の正否も個別監査。粗いセルと細セルを区別、事後選択したセルは確認結果と呼ばない。
- S42卓記述統計のみ。人間の外部数値の分母・巡目・待ち定義が一致しない場合は数値比較をしない。対副露聴牌率は外挿困難な補助研究、教材採点・中核の人間確率には用いない。新規拡張を確認用に使う場合は開封前に独立半荘単位で隔離。
実装 classify-waits.mjs: 手組み例12件を関数そのもののV8実行で検査、全成功。テストファイルも保存。Node/独立コア/実牌譜/性能の検証は未実施。元の私的L1 v2 ZIPと970半荘原本・鍵をこのチャットの実行環境から再取得できず、新集計0。
## L2 初期の分岐受領監査（実対局・戦術の認定ではない）
既存の公開 runner tests/next/run-p1-v2-dev.cjs の focal arenaExecute、concrete arenaOptions、局風/局数/本場/出現回数ごとの壁seedを確認。実装候補は同一seed/dealer/固定エンジンと方策で元半荘を2回再生し、事前固定した焦点席の判断番号で一度だけ元行動または合法な代替の具体payloadを強制。以後S42固定。新しい行動で元のprefixが変わらないこと、baselineが元牌譜・壁系列を再現することが最低条件。元の焦点席に限定する初期pilot。鳴きの優先打切り・立直2段階・赤牌/ツモ切りの具体選択を別検証し、対応しないpayloadは不成立として記録。代替は公開条件で事前選択し、結果や真手牌による選抜を禁止。共通乱数は同一局境界キーが双方に存在する場合に壁を一致させる。枝の局数が違えば壁系列全体の一致を求めない。
audit-pair.mjs: 元の具体合法手集合、共通prefix/真状態/公開視点/壁/方策・ルールdigest、強制1回、実適用、完走・合法、score/escrow保存、初期席同点順、baseline元logと壁系列の再現、差分出力を検査する受領器。合成1正常＋19拒否例を同一関数のV8実行で全成功、Nodeテストファイル保存。digestやリーク遮断等は検証器の入力申告であり、この受領器だけで独立確認したことにはならない。実runnerがprivate監査領域でhashを算出し、policyに秘密状態を渡さないことを別途コード/poison監査する。役符清算は独立監査が別途必要。
次ゲート: 私的原本を復旧し、固定seedから1局面baselineの元牌譜再現、同一判断の2具体合法行動に対する前状態同一性・強制適用・完走を確認。次に数局面の事前選択smokeと失敗率、実測時間、再現性。共通乱数の分散改善は実測、真状態条件付きの1ペアから個別確率・最適性・人間での効果は推定しない。半荘クラスタ単位での型別差・対象母集団・方策を別カードで固定。実モデル/API/新しい半荘生成・CI起動なし、既存拡張の処理を妨げない。
