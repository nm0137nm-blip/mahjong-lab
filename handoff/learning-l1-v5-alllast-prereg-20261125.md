# L1 v5 オーラス開始時の順位分布（探索・集計前固定）
対象: 初期970半荘のうち南4局へ進んだ半荘。南4局の最初の配牌直前（同局連荘の2回目以降を除く）の4席。南4へ到達しない終局を除外し、その件数を報告する。入力は公開点棒・起家・親・局/本場/供託のみ。最終順位を結果とし、点差・層の定義には結果を用いない。順位は点数降順、同点は起家からの順番。局風/局数、座席→固定ID、点棒＋供託=100000、順位・最終点の一致を検査。真の山/他家手牌/Qは使用しない。
主セル: 開始時順位1～4（全条件）、追加1軸で親/子または直近競合者との非負点差。1着は2着、2着は1着、3着は4着、4着は3着との点差。点差帯 0～3900 / 4000～8000 / 8100以上（100点単位）。親×点差の全交差は今回は作らない。各セルの最終1/2/3/4着率と件数/半荘数/局数を表示。開始順位を混ぜない。各半荘1対象局、各順位1席。半荘単位2000回bootstrap、95%百分位区間。100半荘かつ200局、陽陰各10、CI全幅10pp以下の個別割合のみ暫定支持。全順位分布が支持されないセルは正規化で補完しない。参考段位ptは四順位分布が揃うセルのみ、固定の既存Tenhou評価表（特上6段東南[75,30,0,-120]、鳳凰7段東南[90,45,0,-135]）に後付けし95%CIを計算する。段位ptの精度幅は未規定につき教材の採点・行動推奨には用いない。
S42同士・初期970開発のみ。南4到達の条件付き、打牌介入の効果でも人間卓の個別局面確率でもない。親続行や西入を含む最終結果。点差の反転・放銃許容や押し引き最適性はL2の別実験。点差帯は実装上の事前選択であり点差だけで判断しない。独立確認は拡張コーパスを事前分割して行う。生牌譜・個別行・鍵は公開しない。
