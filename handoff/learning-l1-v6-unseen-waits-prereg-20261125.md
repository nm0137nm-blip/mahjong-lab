# L1 v6 受理済立直の公開情報上の未見待ち枚数（集計前固定）
対象は初期970半荘の受理済立直7711件。宣言打牌直後、宣言時点までの表ドラ表示牌、全河（鳴かれた打牌含む）、公開された全副露/槓のうち河と重複しない牌、自分の残り門前手牌を数える。暗槓は牌種が公知で4枚と数える。赤5を通常5と統合。構造待ちはL1 v3と同じ。各待ち牌種ごと4−公知枚数を合計。真の山・他家の隠し手は使用しない。未見枚数は他家の手牌・王牌にも存在し得るため山残枚数ではない。フリテン等でロン可否が異なっても構造待ちとして扱う。宣言牌での放銃など未受理立直は対象外。宣言以降の表示牌・副露・打牌は入力に含めない。
公知牌をイベント加算と現在までの河＋現在の副露形＋表示牌＋自手の独立再構成で照合し、各牌種0–4、二重カウントなし、受理済件数とv3/v4の待ち形/役割/結果が一致することを要求。主セル:先制/追いかけ×未見枚数0–2/3–4/5–6/7以上、各々待ち形（両面のみ・混合・両面なし）または巡目（1–6,7–12,13+）を一軸だけ追加。未見0件は別報告。和了/放銃/被ツモ率、参考局収支（支持幅未固定のため推奨用にはしない）。半荘クラスタ2000bootstrap、支持100半荘/200局/陽陰各10/CI幅10pp以下。全探索データのみ、S42卓の条件付き記述。待ちの未見枚数による因果効果・人間卓の確率・実山推定ではない。点数閾値や枚数帯は開発側の事前選択。独立確認用追加コーパスは未閲覧。
