# P1 準備 / Phase 0 待機時間を利用した並行作業
第三者確定版 p14 のP1（確率校正、局面内危険牌順位、条件付き失点、即時期待放銃損失）に対応。作業は評価設計とメトリクス単体試験に限定する。Phase0の合格を先取りせず、新モデル学習や最終holdoutを開始しない。
- 数値閾値は資料の「事前固定」「相手ファミリーごとの分離評価」「不確実性の高い推定を弱める/非表示」を具体化した開発側の提案であり、第三者が指定した数値ではない。
- 既存のlegalRonラベルは選択されたロンではない。各家への条件付き支払いと合法ロン可能性の積を「合法ロン機会ベース期待損失」と定義。実際の支払いを扱うには複数ロン・頭ハネ・三家和などを含む取り決め、裏ドラの扱い、他家方策を明示し別検証。
- 既存特徴量の現物/リーチ確定処理や教師の可否ラベルを独立エンジンで再照合する。古いデータ・候補対局からholdoutを使い回さない。
- 既存317判断の具体的行動の不一致7件は、元の監査artifactを読み取る新CIで明細を再現し、型別に評価する。旧S42-adapterは凍結し、後から過去の成績を同一Mortalとみなさない。
- この変更は本番への反映なし。次は差分の原因に基づいて修正/比較対象の定義を決定し、P1の教師・全体評価コードの検証へ進む。
