# Phase 2.5.5 — 鳳凰卓を目指す AIコーチ

## 目的
鳳凰位レベルを目標とした独立した熟練者の視点で、鳳凰卓で通用する判断力を育成する。Mortalへの一致を目的にしない。S42の低推奨度だけで重大ミスと断定せず、局面に基づく根拠と再利用できる判断基準を重視する。AIが実際の鳳凰位資格・雀力を持つと主張しない。

## 使い方
1. 打牌・鳴きなどの選択後に「詳細」→「AI解説」を選ぶ。終局後の低推奨度レビューでも利用可能。
2. 必要に応じ質問を入力（任意）。内容を確認して「解説依頼をコピー」。
3. 「ChatGPTを開く」からChatGPTに移動し、貼り付けて送信する。自動コピー非対応時は選択されたテキストを手動コピーする。
4. 終局画面の「全判断を振り返る・AI解説」では、記録済みの判断を選択できる（現対局中に保持している判断のみ。自動スルーなど未記録の行動は対象外）。

## 送信内容
判断直前の自分の手牌とツモ牌、公開牌、河の打牌種別・立直宣言・副露された牌、点数・順位、自風・本場・供託、残り山枚数、選択と合法候補、牌効率、取得済みのS42合法手Q・推奨度。S42未取得でも依頼可能。旧版の記録は欠落を明記し、推測補完しない。

他家の未公開手牌、実際の山の中身、後続の結果はコピーしない。ChatGPTへの貼り付け・送信はユーザーが行う。API連携・自動送信・有料APIキーは使用しない。LLMの回答はS42の内部判断理由ではなく独立した見解であり、精度・雀力は未実証。

## 定量評価
Mortal Rating・Softmax温度0.1・悪手率5%未満の計算ロジックはPhase 2.5.4のまま。古い記録の数値は新たな計算へ変換しない。S42のリーチ・カンにおける段階別の評価と東風戦へのモデル適合性の制約も維持。
