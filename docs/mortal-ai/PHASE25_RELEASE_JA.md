# 麻雀LAB Phase 2.5 — S42判断分析・振り返り

2026-11-18 JST / 本番導入前の仕様と検証記録

## 何が変わるか

1. 打牌後の比較表示を **自分とMortal-S42だけ**にします。従来の電脳麻将CPUはゲーム内の対戦相手として残りますが、CPU推奨の表示・比較は廃止します。
2. 詳細解説を「牌効率・受け入れ」「S42の定量評価」の2タブに分離します。
3. 牌効率タブでは自分の打牌、S42の打牌（打牌を推奨した場合）、牌効率上位候補について、牌姿・向聴数・直接有効牌・公開情報を差し引いた残り枚数を表示します。S42がリーチ等を推奨する場合、切る牌は推測せずその旨を示します。
4. S42定量評価タブでは **合法行動のモデルQ値、モデル内順位、自分とS42のQ差**、次の暫定学習指標を表示します。
5. 対局終了画面に学習指標を表示。**Mortal推奨度5%未満の打牌**を、自分の当時の手牌・公開牌・河・ドラ表示・点棒で振り返れます（最大25局面）。
6. 計測用対局の完走分にS42集計結果を保存。トップの成績表示では東風／半荘別に平均判断指数、一致率、暫定悪手候補率を集計します。既存の順位・和了・放銃等の成績は維持し、旧データにはS42分析を後付けしません。

## 指標の定義：従来AIのレーティングとは異なります

本リリースの「判断指数」は**独自定義の0–100点指数**であり、天鳳段位・雀魂段位・NAGAレーティングに対応する数値ではありません。

- 分析可能な打牌に限り `bestQ` は合法行動の最大Q、`chosenQ` は自分の選択のQ。
- `relativeGap = (bestQ-chosenQ)/(bestQ-worstLegalQ)` を0–1に丸めます（分母が0の場合は極小値で除算）。
- `判断指数 = round(100 * (1-relativeGap))`。
- `一致率 = S42最良行動と一致した回数 / 有効な比較回数`。
- `悪手率 = Mortal推奨度が5%未満の解析済み打牌数 / 解析済み打牌数`。鳴き・スルーは分母から除き、リーチ宣言打牌は含めます。
- `Mortal推奨度 = softmax(Q / 0.1)`（合法行動のQのみで計算）。5%**未満**を悪手判定とし、5%ちょうどは含めません。これはMortal牌譜検討で用いられる推奨度の定義に合わせたものです。
- 対局間の判断指数・一致率は解析対象判断数で加重し、悪手率は解析済み打牌数で加重します。解析未完了・モデル未設定・不適切な行動段階・比較不能な選択は分母から除外します。旧版のQ差30%基準の記録は新悪手率には換算しません。

**注意：Q値・Softmax推奨度は点棒期待値・放銃確率・勝率ではありません。** ニューラルネットワークのQ値は「牌効率点＋守備点＋打点」の厳密な足し算ではないため、点数ごとの正確な寄与度の因数分解はできません。「S42の定量評価」画面でできるのは、合法手間の相対比較です。

## CPU対戦相手の強化

対戦相手は現行の電脳麻将AIを維持。S42の評価をそのまま3人のCPUに適用するには、各席に対応した公開情報だけの入力系列、リーチ・鳴き・カン・和了の行動変換、推論待ちの同期制御、iPhoneの端末内メモリ・速度テストが必要です。今回は**まだ対戦相手をS42へ置換していません**。品質検証を省略した「S42級CPU」という表記もしません。

## プライバシー・安全

- モデル `model.onnx` はユーザーの端末内IndexedDBからロード。GitHubリポジトリに重みをアップロードしません。
- 局面リプレイには**人間が見られる情報のみ**保存。他家の非公開牌・実山配列を複製しません。復習データは端末内にのみ保存。
- 対局・学習ログを外部へ送る分析基盤は導入しません。
- 既存の記録モードでの保存条件は維持。デバッグ/途中退席の対局は成績に混ぜません。
- 課金・有料契約・決済・有料ランナーは使用しません。

## 重大な制約

- 独自判断指数は人間の棋力を外部サービスと互換のあるレーティングとして定量化するものではありません。
- 対局中の鳴き、リーチ、カンなどはS42の選択行動に含まれますが、今回の終局後**打牌比較**では比較可能な打牌のみに限定します。今後、各行動フェーズの正確な同期とレビュー対象拡張が必要です。
- モデル由来の強さの評価と、個別判断を正しいと断定できることは別です。
