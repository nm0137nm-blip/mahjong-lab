# Mortalを根拠付きで説明できるコーチの検証方式（2026-11-18）
目的はMortalの内部理由を断定することでも一致率を100%にすることでもない。人間が再現できる強い判断を、判断時点の公知情報から検証可能な仮説として伝える。Mortal公式FAQ https://github.com/Equim-chan/mjai-reviewer/blob/master/faq.md も、Q評価の正確さそのものが対局AIの最終目的ではないと説明している。
## 独立評価（第1段階）
開発用の実対局から前判断スナップショットとMortal-S42の合法Qを分離して保存。43,673,425バイトの既存S42 ONNX、SHA-256 30381bf21389e2d25d3edf48fed11bf772336ef3daeee67d1bdae7fb9dd30cb4。対象は同一判断ID、アプリ合法行動ID集合と推論マスクが完全一致する非自明な選択。欠損・不一致・強制手は理由別集計。ユーザーの選択、Q、AI候補で計算対象を優先する情報、対局結果、隠し牌を出題に含めない。候補計算は牌効率で固定。
同じblind.jsonを旧・新コーチの独立チャットに渡し、同じモデル・推論設定・回答形式で比較。問題選択や学習用事例との重複を固定して記録する。順位戦の効用を含む現行のゲームルールで判断させる。Q差は参照モデルのみの相対評価であり、真の期待値・和了率・レーティングではない。全回答が合法かつ有効でなければ比較不成立。正解タイと厳密一致を分ける。平均Q差、合法集合のQ範囲で規格化した差、上位2位以内、打牌／反応別を報告。
## 説明（第2段階）
第1段階の回答ファイルを確定してから参照Qを開示（CLIは有効回答を要求するが、ファイルの改変防止を保証する仕組みではない）。上位候補と本人の判断を比較し、最有力の理由仮説、対抗仮説、反証条件を示す。牌姿・向聴・ドラ・役・点差・他家別事実を照合できる複数のclaimsを要求し、誤った値や重複を検出。機械採点は記述した事実だけであり、仮説の十分性・都合の悪い事実の欠落は人の審査が必要。
## 条件変更（第3段階）
同じ合法手牌のままドラ表示を変更する対、同じ南4局親のテンパイ選択のまま点差を変更する対を、独立したMortal推論で評価する。2候補のQ差がAからBへ増減する方向を開示前に予測。両局面でQがほぼ同値なら数値誤差の扱いに注意。比較はモデルの出力感度であり内部理由の因果証明ではない。ドラ対は既存教材と同系統なので未見卒業試験に数えない。2対は最小限のパイロット。今後、鳴き・押し引き・巡目・他家の仕掛けなどの独立した未見対を追加する。
## 合格判定
パイロットで数値閾値を先に断定しない。次回の拡張では複数の独立した対局単位で学習用と未見評価用を分け、序盤手組み、攻撃対守備、鳴き、立直、終盤順位戦で層化。旧版、牌効率・単純守備、可能であれば上級者による選択との比較を設定する。回帰なく合法判断100%、重大な事実矛盾ゼロ、旧版比でQ差が改善することを最低の前提にする（強さの十分条件ではない）。対局単位の相関を踏まえ、差の信頼区間と複数チャットでの再現性を記録する。自由記述は版を隠して、根拠の正確さ・主要候補比較・判断の説得力・反証可能性・指導の有用性を各0〜2点で審査。2点=具体的で妥当、1点=部分的または不十分、0点=矛盾または欠落。上級者による独立審査がない限り人間の鳳凰卓級とは認定しない。Mortalとの不一致は説明の妥当性で審査し、機械得点とは別に記録。
## 実行手順
GitHub Actions coach-s42-benchmark.yml（開発ブランチのみ）でS42-ledと牌効率-ledの生成半荘各1回、合成対照4局面を予定。前者も立直後の打牌や槓の詳細でMortalを完全再現するものではない。成果物の出題と参照キーを別アーカイブに保存。実対局は麻雀LABの自前生成で、天鳳牌譜の流用ではない。
```sh
node scripts/coach/s42-benchmark.mjs grade reference.json answers.json report.json
node scripts/coach/s42-benchmark.mjs reveal blind.json reference.json answers.json stage2.json
node scripts/coach/s42-benchmark.mjs claims blind.json explanations.json fact-report.json
node scripts/coach/s42-benchmark.mjs contrast contrast-reference.json predictions.json contrast-report.json
```
## 現在の検証範囲
実エンジンを読み込んだ9件の直接アサーション（ブラインド不変性、Q差計算、マスク不一致、未回答、古いQの拒否など）、追加6件の合成ラベルによる開示・事実チェック・対の方向判定アサーションが通過。対照4局面の牌数・点棒・合法打牌・立直条件を実エンジンで確認。indexと収集スクリプトの構文は確認。実際のONNX推論を含む新ベンチマークのCI結果と独立LLM回答は未取得。コーチの雀力認定、本番変更、追加課金はなし。
