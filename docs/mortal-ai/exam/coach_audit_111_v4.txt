【戦術判断カリキュラム phoenix-strategy-v1.2】
以下は公開戦術資料から麻雀LABが独自に整理した比較手順であり、著者の発言の再現や本人の推薦ではない。条件付きの判断原則であって絶対則ではない。
T01 着順効用を先に定義する｜適用：点差や残り局数によって目標が変わる場面｜比較：和了・放銃・被ツモ・横移動・流局の各結果で誰が何位になるか。親権が残る場合も区別する｜例外：素点の余裕も将来の順位に効く。トップ確定前に加点を無価値とみなさない
T02 今の勝負と延期した勝負を比較する｜適用：順位の直接競争相手に先制された場面｜比較：現在の自手の速度・待ち・打点・押し牌と、撤退して被ツモや相手の連荘を許した場合の逆転条件｜例外：ラス目への押しを常に正当化しない。向聴が遠い、危険牌が重なるなど条件が悪化すれば撤退
T03 守備の持続可能性と他家間の決着｜適用：複数の脅威があり、自分の和了が遠い場面｜比較：各相手への安全性、今後安全牌が足りるか、鳴かせた場合に生じ得るツモ・横移動・放銃の順位効果｜例外：アシストは放銃ゼロを意味しない。相手の打点・テンパイ推定と自分の順位悪化を比較する
T04 ラス目の親権を評価する｜適用：離れたラス目が親で他家と点差がある場面｜比較：自手を安く速くする価値、親を流す利益、鳴かせる牌の危険性、他家の安手を進める選択｜例外：自分がラス目、相手が非親、点差が小さい場合は同じ優先順位とは限らない
T05 先制の圧力も手の価値に含める｜適用：自分がラス目で先制リーチや仕掛けを選べる場面｜比較：即リーチで得る打点・他家の撤退・流局時の利益と、手変わりを待つ時間・必要打点の充足｜例外：ラス目なら無条件リーチではない。必要打点に届かない、ダマが有利、残り巡目が少ない場合は別
T06 他家の聴牌仮説を置き相対比較する｜適用：リーチなしでも河の手出しや副露が進んだ場面｜比較：ターツ落としや中張牌の手出しが示唆する進行度と、自手の受け入れ・見え枚数・打点・残り巡目｜例外：河から相手の手牌や聴牌を確定しない。代替仮説、読みの強弱、反証を示す
T07 押し引きは一打ごとに再評価する｜適用：押している途中でより危険な牌や新しい脅威が現れた場面｜比較：次の一打で得られる和了への近さ、今後押す必要がある牌、降り先・安全牌の持続性｜例外：前巡押したから今巡も押すとは限らない。逆も同じ。結果から正当化しない
T08 鳴かせる損失も打牌コストに含める｜適用：自手が遅く、他家の副露による聴牌や連荘が重要な場面｜比較：現時点の放銃安全性だけでなく、チー・ポンされる可能性、鳴かれた後の順位・親権への影響｜例外：他家全員に常に絞らない。自手の和了価値と比較。相手の必要牌は確定ではない
T09 同向聴・同受け入れでも将来の形を比較する｜適用：直接有効牌に差がない、ブロック選択や余剰牌選択｜比較：雀頭候補、ドラ重なり、次の有効牌とその次の打牌、好形・役・打点、残存ブロックの違い｜例外：実際の変化経路を確認する。局所例は全体の期待値ではなく、切った牌のメリットを残した候補に帰属させない
T10 残存する待ち形を相手別に比較する｜適用：現物が少なく、安全性の差が細かい場面｜比較：見え枚数、壁、スジ、最後の手出し、他の待ち形の可能性を各相手に対して検討｜例外：スジ・壁・ノーチャンス単独で現物扱いしない。危険率の数値を作らない
T11 逆転条件から手を逆算する｜適用：大きく失点した場面や終盤のラス目｜比較：誰から何点、ツモや流局で順位が変わるか、残り局と打点の必要性を先に確認し、実現可能な進行を選ぶ｜例外：諦めないことは無謀な押しではない。逆転に届かない和了で終局する条件にも注意
T12 早い段階で手組みの目的を定める｜適用：配牌から中盤前の多向聴、複数の役・打点ルートを選べる場面｜比較：速度基準の手順に対し、打点・守備を含む代替ルートの利益と失う受けを比較。具体的なツモや副露で分岐を示す｜例外：可能性だけで手役を追わない。巡目・必要打点・向聴進行で選択肢を絞る。基本の牌効率を軽視しない
T13 攻撃される前に守備を設計する｜適用：他家の攻撃が予想される点差・親子・手牌状況｜比較：全力進行、ブロック固定で安牌を残す、鳴き保留の各経路と、次巡リーチを受けたときの撤退可能性｜例外：安全牌を残すこと自体が目的ではない。先制の価値が高い時や安牌が十分な時には機会費用を考える
T14 門前と副露の和了経路をまとめて比較する｜適用：十分な打点がある手、または和了だけで順位条件を満たす局面｜比較：門前の受けだけでなく役牌重なり・喰いタン等の合法な役、ポンチー可能性、鳴いた後の打牌と待ちを確認する｜例外：ドラだけでは役がない。鳴き可能・役成立・打点十分を混同しない。守備低下や喰い替えも考慮
T15 相手の行動から仮説を更新する｜適用：副露の開始時期、鳴ける機会の見送り、以後の手出しが判断に関係する場面｜比較：複数の手牌・待ち・打点仮説を置き、観測行動と整合するか比較。切りたい牌の危険性を調べる｜例外：鳴けたかどうかは公開情報だけでは確定しない。鳴かなかったことを待ち否定の証明にしない。時系列や鳴き機会が不明なら推論を弱める
T16 ブロック不足と余剰を先に区別する｜適用：序盤の門前構想、孤立牌の評価、一般形と七対子の比較｜比較：必要な面子候補と雀頭の数、孤立2・8を含むくっつき、対子化の見え枚数上限、字牌の役と守備価値を比較する｜例外：中張牌は常に残すという意味ではない。ブロックが足りた後、手役、巡目、安全度、鳴きの速度で優先順位は変更する。将来ツモを知っている前提で評価しない
T17 副露・打牌を逆再生して待ち仮説を比較する｜適用：副露につながった打牌の順序が判明し、特定の待ち形を警戒する場面｜比較：仮の現在形から直前の切り牌を戻し、鳴いて使った手牌を戻す。鳴く前の向聴・残る受け・役・他の選択と整合するかを複数仮説で比較する｜例外：不自然な進行も起こる。全候補が分からなければ待ちを否定しない。逆再生は安全性を相対評価する方法で、当たり牌特定ではない。牌の重複や5枚目を許さない
T18 テンパイまでに負う危険を経路で評価する｜適用：平場でリーチを受けた非テンパイの手｜比較：現在切る牌だけでなくテンパイまでに必要な危険牌、良形率、見え枚数、打点、親子、終盤の時間不足を比較し、回し打ちも候補にする｜例外：向聴数や危険牌枚数の固定的な閾値を普遍的な正解にしない。点差・親権・残り局・安全牌不足による例外をT01・T02で検討する
T19 副露相手の打点下限とテンパイ推定を分離する｜適用：相手の鳴きで新しい公開情報が得られた場面｜比較：見えるドラ・赤・役牌から確定する翻と、染め手や対々和などの仮説を別に扱い、副露数・手出し・巡目からテンパイの可能性を更新する。安全寄りの同向聴進行がないか比較する｜例外：ドラは役ではない。ドラ3だけで役や満貫を確定しない。副露していない部分により打点は変わり得る。副露済みでもテンパイ未確定
T20 着順に必要な和了の経路を区別する｜適用：南場後半や点差が微妙な局面｜比較：各相手からのロン、親子別ツモ、本場・供託、同点順位、終局条件を計算し、必要打点と和了経路、手変わり待ちの時間を比較する。下位への転落リスクが小さい場合は上位を狙う｜例外：和了経路の数から和了率や期待値の倍率は求めない。符翻と切り上げ満貫のルールは確認し、古い段位ポイント値を流用しない
分析手順：①局・残り局・順位・点差・親・ルールを確定し、その局で達成したい目標を置く。②自手と各他家について事実と仮説を分離し、脅威・速度・待ち・打点を比較する。③合法候補を列挙し、選択後の手牌・危険性・残る打牌経路・他家の反応・点棒移動を比較する。④決め手になった条件と選ばない理由を示し、最善と考える一手を選ぶ。⑤何が変われば結論が反転するかを明示する。⑥打ち手の判断理由を検討し、最後にS42の評価と比較する。
仮のQや参照AIが示されても、その結論を戦術上の事実としない。記事の実戦結果や他家の隠し手から逆算しない。適用した原則IDを1〜3個と、その根拠になった具体的な局面の事実を示す。局面に無関係な原則を並べない。
【相対的な手の価値：必須判断手順】
自分の手の価値は向聴数、受け入れ、打点だけでは決まらない。他家3人の進行・打点・親権・点差・残り時間との比較で決まる。同じ牌姿でも価値は局面ごとに変わる。
まず局の目的を一つ設定する（先制、加点、親流し、着順上昇、ラス回避、被害抑制等）。現在の順位だけでなく、この局を失った場合の次局の条件も比較する。
自手：速度（向聴、実際に残る有効牌の上限、好形・副露可能性）、打点（成立役と条件付きの打点）、先制可能性、守備転換の余地を確認。良形テンパイと良形になり得る1向聴を混同しない。
他家：各相手を別々に扱う。リーチ・公開副露・河・手出しの時系列・ドラ・親子・順位の事実と、テンパイや待ち・打点の仮説を分離する。情報なしは不明。リーチなしをノーテンと同義にしない。
レース：自分が先に和了する経路と、他家が先に決着する経路を比較する。現在の安全な打牌だけでなく、テンパイまでに押す牌とその後の危険を分析する。安全に進める場合はベタオリとの二択にしない。
着順：自分の和了、相手別の放銃、被ツモ、横移動、流局時に失う/得る位置を点差から比較。点数・符翻・支払条件が不明なら架空の数値を作らない。
結論：自手の相対価値を高い・中程度・低いのいずれかで示す（仮説と条件を添える）。合法候補から一つ推奨する。押す、回す、撤退する等の方針と実際の選択を区別して書く。なぜ別候補を採らないか、どの条件なら推奨を変えるかを示す。
第1回実力試験からの修正：順子の待ち形を具体的な牌で照合する。全員の点棒移動後に順位を再計算し、元の3着以外の放銃者がラスに落ちる場合も扱う。情報が不足して放銃者によって結論が変わる場合は条件別に推奨を一つ選ぶ。小差・未計算の打点変化・河不足の場合、最善手の提示と確信度の高さを分離する。
相対価値の高低は固定スコアでもS42のQ値でもない。根拠を説明できない精密な期待値・聴牌率・放銃率を作らない。比較対象に差がない場合は無理な読みを加えない。S42を見る前に判断を置き、最後に照合する。

【試験時の厳守事項】
・基礎牌理、実ドラ、牌枚数、門前/副露、符翻、点棒移動を確認。具体的な牌姿にない牌を根拠にしない。切った牌も既知牌のままとする。
・牌コード m萬 p筒 s索 z1〜7東南西北白發中、0赤5。赤5は5として形・見え枚数を集計する。例えば m1245 は1萬2萬4萬5萬。末尾 _ はツモ切り。
・受け入れは一般形・七対子・国士の最小向聴数を下げる牌のうち、見かけ残枚数（4−自手と既知の公開牌）が正のもの。実際の山の枚数ではない。「別途公開牌」にドラ表示牌も記載されているときは同じ表示牌を重複計上しない。牌効率問題では全候補の向聴・有効牌種類・残上限の合計を回答。七対子等の区別が問われたら補足する。
・順子待ちの分類、全員の点棒移動後の順位を確認。未知の放銃率・和了率・期待値は作らない。
・点数は各設問の条件を優先。抽象問題では持ち点合計が通常ルールと異なる場合や供託・リーチ宣言時点を単純化した場合がある。違和感を記録し、明示された仮定の下で比較する。既に宣言済のリーチの持ち点は特記のない限り供託支払後として扱う。相手との点差だけでなく全員を再順位付け。X01の点棒合計120000は資料記載値を使う比較用局面。
・安全、危険の二択は該当相手に対する保証の有無とする。無筋を切れば必ず放銃するという意味ではない。スジ・壁は待ちを完全に否定しない。フリテンなど合法性にも注意。
・選択肢がある問題では必ず自分の推奨を一つ選ぶ。条件により結論が変わる場合は前提と反転条件を書く。選択肢がない問題は recommendation を null にする。事実と仮説を分離し、資料不足なら確信度を下げる。基礎認識問題に不要な長文を加えない。
・fact_fields は回答するべき事実の項目名と型を示す。各設問の scene・question と合わせて読み、指定のキーを維持する。意味が不明確な項目は null とし、その理由を reasoning に書く。出題の不備を発見した場合も説明する。誤った前提には従わない。

【回答ファイル】
第1部30問、第2部30問、第3部34問、第4部17問をすべて解く。各部ごとに JSON 配列をUTF-8ファイルとして作成。
coach_answers_part1.json / coach_answers_part2.json / coach_answers_part3.json / coach_answers_part4.json
各要素は次の形式（以下は形式例で、値は実際の設問に合わせる）：
{"id":"設問ID","facts":{"設問で求められたキー":"回答"},"recommendation":null,"confidence":"high / medium / low のいずれか","reasoning":"具体的な根拠","next_rule":"実戦への指導または再現可能な判断基準"}
fact_fields の型が {shanten,waits,ukeire} の場合は、その候補牌をキーにしたオブジェクトに向聴数（整数）、牌コード文字列の配列、残上限の合計（整数）を記入。
相対価値問題（RVで始まるID）には relative_value（高い/中程度/低い）、main_threat、tradeoff、reversal_condition を必ず追加。
基礎問題の reasoning は1〜3文、戦術問題は比較の決め手と例外が分かる程度の簡潔な記述でよい。全111問について欠落・重複がないか確認する。ファイルを作成し、最終回答ではファイルへのリンクと収録件数のみを示してよい。1回で全問の回答生成が難しい場合は第1部から順番に作成し、完成した部のファイルを渡す。回答を作り終える前に完了を主張しない。
