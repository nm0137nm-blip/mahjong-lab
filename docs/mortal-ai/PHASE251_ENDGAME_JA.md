# 麻雀LAB Phase 2.5.1 — 終局・連荘ルール（2026-11-18）

## 採用ルール
- 東風戦の東4局、半荘の南4局に適用。親の和了・聴牌通常流局は、精算後に親が**単独1位**なら終局（30,000点未満でも可）。2～4位または同点首位なら連荘。
- 親が連荘できない通常流局（ノーテン）、子の和了では最終局を終える。
- 九種九牌などの途中流局は、親がトップでも終局とせず続行する。
- 誰かが0点**未満**になった場合は局数を問わずトビ終了。0点ちょうどはトビではない。
- 元の「延長戦なし（西入なし）」を維持し、終局条件は東4局・南4局を対象とする。

## S42に使われた対局ルールとの相違
Mortal-S42の公開評価の一部は libriichi BatchGame::tenhou_hanchan を使用。
その公式エンジンはオーラス親の連荘時、親が**1位かつ30,000点以上**なら終局。30,000点未満なら親の連荘を継続し、全員30,000点未満なら西入する場合もある。
麻雀LABはユーザー指定を優先し、親が単独1位なら30,000点未満でも終局、西入なしとする。
S42は行動評価モデルであり、今回のルール変更によってその学習／検証環境と麻雀LABが完全一致するわけではない。
