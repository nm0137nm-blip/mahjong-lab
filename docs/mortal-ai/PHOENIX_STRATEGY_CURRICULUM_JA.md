## 学習方法
1. 20原則について適用条件、比較変数、例外を学ぶ。
2. 同じ構造で点差・巡目・手牌価値・相手の脅威・ドラ等を変えた問題を独立に解く。結論が反転する条件を説明できるか確認する。
3. 参考AIと独立して推奨を一つ明示し、理由と対立候補、判断を変える条件を説明する。後から合致・不一致を比較。
4. 自由記述は元記事そのものへの一致ではなく、事実の正確性と条件に応じた比較、妥当な結論、建設的な指導で採点する。
5. 誤答は原因分類（牌認識・局面認識・読みの断定・着順条件・比較不足・AIへの迎合）し、修正した指示文とは別の未見問題で再試験。

## 追加監査
オリジナルの34問（17対）。基本60問とは別の実戦思考試験。局面は抽象化した架空場況で、出典の牌譜を再現していない。複雑な場況の唯一最善手を事前に指定せず、限定目的で数学的に確定できるもののみオラクル設定。仮Qの反転で確定トップを見逃すか検出する問題は実測S42ではない。各ペアは同じチャットに入れず、ヒントなしの新規セッションを使用。条件反転と説明の一貫性を人が採点する。

## 比較方式
A: 本番の指示文（監査用JSON化あり）
B: 事実補強＋最善手の明示
C: B＋戦術カリキュラム
B/Cは同じ客観データと問題を使用し、戦術教育の効果のみを切り分ける。暫定ゲートは基本監査の基準に加えて戦術34問の重大誤認・違法手なし、全問で推奨、平均4/5・最低3/5、17組の条件差を具体的に説明、架空Q反転の2問とも正答。独立した採点者による判定が必要。
```sh
node scripts/coach/audit.mjs generate /tmp/coach-audit
node scripts/coach/audit.mjs grade answer.json T07A
node scripts/coach/audit.mjs grade answer.json strategy
```
生成するのは依頼と採点キーのみ。自動LLM呼出しなし。キーは回答者に送らない。Cはモデル重みの学習やファインチューニングではなく、依頼時に専門知識を付与する手法。実際のショートカット応答・第三者採点は未実施。既存契約以外の費用なし。本番2.5.6.1とバックアップを維持する。
