# 相対価値を中心とするコーチ判断 v1

## 目的
自手の価値を固定点・向聴数・Q値だけで評価しない。自手の和了経路と他家の進行度/打点、残り時間、親権、着順への影響を比較し、今この自手で勝負する価値を評価する。既存の公開記事に基づく20戦術原則を統合する麻雀LAB独自の判断手順で、著者の主張の逐語再現ではない。

## 出力の必須項目
- 推奨する合法選択を一つと確信度。自手の相対価値（高・中・低）は定性的見解であり、固定閾値や実測期待値ではない。
- 自手の速度・打点・待ち・副露による進行・守備転換余地。
- 他家3人について公開事実と推定を分け、最大脅威を指摘。情報が不足していれば不足と書く。
- 推奨手と他候補の代償：現在の押し牌、今後必要になる危険牌、先制機会、撤退後の被ツモや親連荘、横移動、流局、順位条件。
- 結論を変える条件、打ち手の思考への指導、最後にS42との比較。

## 検証
同じ自手を保つ6対12問を追加：他家の先制攻撃、残り時間、順位、公開副露の翻数、降りることの費用、現物で進めるか。抽象的な架空問題であり、完全な実戦牌譜ではない。点棒移動に供託を除いた比較用条件がある場合は明記。閉じた目的がある設問だけに推奨オラクルを置く。
v3（戦術原則）とv4（相対価値を中心とした構造化手順）の入力問題と回答形式は同一。v4だけに判断手順を追加する。客観事実・合法選択・必須出力項目を機械採点。自由記述は、人による評価で自手の価値の根拠、相手別脅威、比較の説得力、推奨を反転させる条件を審査する。単に脅威が増えたら折りるという硬直的なルールを合格させない。

```sh
node scripts/coach/audit.mjs generate /tmp/coach-audit
node scripts/coach/audit.mjs grade answer.json RV01A
node scripts/coach/audit.mjs grade answer.json relative
```
