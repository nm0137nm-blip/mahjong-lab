# 麻雀LAB Phase 2.4 — Mortal-S42 AIコーチの使い方

## 初回設定（1回だけ）

1. [Mortal-S42 ONNX 公開ページ](https://huggingface.co/xzhe121/Mortal-S42-onnx/blob/main/model.onnx)から `model.onnx` を取得するか、以前保存した同名ファイルを使います。
2. 麻雀LABのトップ画面にある「Mortal-S42 AIコーチ」でファイルを選択します。
3. 「Mortal-S42 準備完了（端末内推論）」と表示されたら完了です。
4. モデルのサイズは **43,673,425 bytes**。SHA-256が公開登録値と一致する場合のみ利用します。不一致なら拒否します。

モデルはブラウザの**端末内IndexedDB**に保存されます。ファイルが消去されない限り毎対局で選ぶ必要はありません。Safariのサイトデータを消去した場合は再度読み込みます。

## 対局中

- **自分が切る前は推奨を見せません。** 自分で考えて切った後、手牌の近くにS42の参考判断を表示します。
- S42の推奨は打牌に限らず、リーチなどの別行動になることがあります。リーチ推奨だけでは具体的な切り牌を示しません。
- 「詳しく」で牌効率の比較を確認できます。
- 未設定やエラー時は従来の**牌効率コーチ＋電脳麻将CPU参考判断**が利用可能です。S42が対局本体のCPUを置き換えるわけではありません。
- S42のQ値は**局収支の期待点数・勝率・放銃率ではありません。** AIの判断を正解・ミスと断定しない表示にしています。

## 安全性

- 公開WebサイトのJavaScriptとWebAssemblyを初めて読み込む際に静的ファイルの通信が発生します。
- **対局情報・個人の成績・モデルの内容は外部送信しません。** 推論は端末内で実行します。
- Safariでオフライン保存が拒否された場合は、一部のS42機能がオフラインでは利用できない可能性があります。対局自体は従来エンジンで継続します。
- 対局操作に伴う**購入・決済・有料契約はありません。**

## 技術と検証

- モデル: Mortal-S42 ONNX。学習済みモデルの強さの検証は公開元によるv4系比較が参考。S42が公式4.1bそのものという主張はしていません。
- 牌姿・場況: Mortal `libriichi` （AGPL-3.0-or-later）由来のWebAssembly局面変換器、Python側の公式変換とバイト完全一致の検証あり。
- 推論: ONNX Runtime Web 1.21.0（MIT）。
- 品質ゲート: 393px Chromiumで実際の東風戦・半荘戦の完走とモデル復元を検証、JSエラー・他サイトへのリクエスト0件。**iPhone 17 Safari実機は未検証**。
- GitHubの公開ブランチ内の `scripts/mortal/build_browser_encoder.py` および `assets/mortal/LICENSE.AGPL` にWASMの再現手順とライセンスを保持。学習済みモデルの重みファイル自体はGitHubに保存しません。

## 旧版への戻し方

S42を読み込まなくても基礎版のCPUコーチが使えます。Webサイトそのものの旧版へ戻す必要がある場合はGitHubの過去のコミットに戻せます。計測成績は端末内に保存されるため、Safari側のサイトデータを消去しないでください。
